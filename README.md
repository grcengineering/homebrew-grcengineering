# homebrew-grcengineering

Homebrew tap for [GRC Engineering](https://grc.engineering) open-source tools.

```sh
brew tap grcengineering/grcengineering
brew install nthpartyfinder
```

## Formulas

- [`nthpartyfinder`](Formula/nthpartyfinder.rb) — discover Nth-party vendor relationships via DNS analysis. [github.com/grcengineering/nthpartyfinder](https://github.com/grcengineering/nthpartyfinder)

Formulas here are kept in sync with each project's own releases — see each project's
`RELEASING.md` / `scripts/sync-homebrew-formula.sh` for how.
