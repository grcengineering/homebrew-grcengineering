### Known gaps (open, not waved through)

- **Approving reviews are not required on `main`.** Scorecard scores `Code-Review`
  0 for this repo. The cause is structural, not neglect: a solo maintainer cannot
  self-approve, so turning the requirement on would block all work. Remediation is
  a second maintainer, then `sscsb harden branch-protection --require-reviews`.
- **The human signing key is device-auth-gated, not hardware-resident.** See
  `.sscsb/policy/signers.toml`; `require_hardware_backed = true` stays set in
  `.sscsb/config.toml` as the standing target, and the remediation is a YubiKey
  `-sk` key.
- **The badge itself is not registered.** Registration needs the maintainer's
  GitHub OAuth and cannot be automated from here.
